# LLM Learning

> 一个 LLM 解决方案架构师的技术学习路径，公开记录从 0 到 1 的完整过程。

## 这个仓库是什么

| 文件/目录              | 内容                |
| ------------------ | ----------------- |
| `learning-path.md` | 完整知识地图：学什么、按什么顺序学 |
| `logs/`            | 每日学习记录，一天一 commit |

## 学习原则

1. **从真实客户问题倒着学**，不背教科书
2. 每个概念都要能回答：「哪个客户问过这个？我下次怎么答？」
3. 事实和假设分开记，不把推断当事实
